# APRS-сеть

Automatic Packet Reporting System — цифровой протокол [[Любительская радиосвязь|любительской радиосвязи]], который передаёт пакеты данных между участниками на одной общей частоте, образуя единую сеть.

Специализированный вариант [[Пакетная радиосвязь|пакетной радиосвязи]]
