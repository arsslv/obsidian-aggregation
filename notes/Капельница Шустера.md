# Капельница Шустера

Прибор для дозированного добавления жидкостей, состоит из двух отверстий:
- закрытое пробкой — для наполнения капельницы (или остановки поступления капель из узкого отверстия при закрытии пальцем);
- с узким носиком — для поступления раствора наружу.
